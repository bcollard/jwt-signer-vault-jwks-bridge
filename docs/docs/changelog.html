    Changelog

    Release notes. Binaries, images and the Helm chart are attached to each GitHub release.

    v0.1.0

    • Vault KV v2 and file sources, with token, Kubernetes and AppRole auth for Vault.
    • Public JWKS and private keyset listeners, with mTLS or Basic auth, ETags and per-keyset names.
    • In-memory snapshots with stale-if-error, staged rotation and the staging guard.
    • Prometheus metrics and OpenTelemetry tracing with W3C trace context propagation.
    • keygen and validate commands.
    • Helm chart and end-to-end tests with Kong Gateway Enterprise in hybrid mode.
